## Publishing Gate

Before any repository URL is added to `atlasanalyse.com` or the Xiangfengxing public website, complete:

- README rewrite for external readers.
- Description and naming cleanup.
- License decision.
- Secret scan including `.env`, API keys, tokens, credentials and test accounts.
- Debug/unfinished artifact cleanup.
- UI screenshot/demo asset selection with rights confirmed.
- Final product-boundary review: no account, auth, payment, backend, API key, real MCP or dashboard exposure unless explicitly approved in a later scope.
